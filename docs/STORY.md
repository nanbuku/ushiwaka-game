# うしわか ―灰色の会社と、しろいいぬ― ストーリー設計（案）

## コンセプト
- 「なんくを笑顔にしたい」という小さな願いから始まり、街を支配する悪の会社との戦いに広がる物語
- うしわかは何をしてもいい。正義の味方としても、悪の化身としても最後までたどり着ける
- 暴れれば暴れるほど、保健所 → 警察 → SWAT → 防衛軍（戦車・戦闘機）と追っ手が強くなり、うしわかも強くなる

## 世界観

### 想いの力
強い想いは、モノに命を宿す。なんくの孤独と、行きすぎた愛情が、ぬいぐるみのうしわかに命を吹き込んだ。

### 悪の組織「株式会社グレイハート」
- 表の顔: なんくが勤める、ひだまり町いちばんの大企業。本社はオフィス街にそびえる「グレイハートタワー」
- 裏の顔: 社員や市民の「心の色（感情）」を吸い上げて灰色の想い〈グレイ〉に変え、それを燃料に兵器を動かす秘密結社
- 目的: 街じゅうの人から心を抜き取り、悲しみも喜びもない「灰色の楽園」を作る計画〈プロジェクト・モノクローム〉
- なんくが毎日つらいのは、会社のビルに仕掛けられた吸い取り装置〈ドレインライト〉のせい

### なぜ、うしわかが狙われるのか
命を持ったぬいぐるみは、想いの力でできた「完成品」。グレイハート社にとって、うしわかは最高の研究材料。

### 2つのルートとエンディング（今の幸福度／悪魔度の仕組みをそのまま使う）
- **しあわせルート（幸福度）**: なんくの「がんばれ」がうしわかに力をくれる。グレイの中の「捨てられた悲しみ」を癒やすと、怪獣は小さなぬいぐるみに戻り、灰谷は泣きながら抱きしめる。街に心の色が戻る。なんくは会社を辞め、新しい一歩を踏み出す → **しあわせエンド**
- **あくまルート（悪魔度）**: なんくは灰色の想いを取り込み、悪の女帝に。うしわかと共にグレイを倒し、会社の最終兵器〈ハート核爆弾〉を手に入れる。街をまるごと吹き飛ばし、ふたりは新しい支配者になる → **あくまエンド**
- クリア後はフリーモード（全部の武器・乗り物が無限に使える。核爆弾も）

## うしわかの成長
- **想いのかけら**: ミッション・ドレインライトの破壊・ぬいぐるみ仲間の救出で手に入る。能力を解放する
- **移動**: 走る速さアップ、二段ジャンプ、壁ジャンプ、空中ダッシュ、耳で滑空
- **技**: 回転アタック、もふもふシールド（弾を防ぐ）、死んだふり（ぬいぐるみに戻って追っ手をまく）、遠吠え（衝撃波）
- **防具**: もふもふベスト（アーマー）、ヘルメット
- **武器**（すべて無限に使える）: 今の武器に加えて、拳銃・マシンガン・ミサイル・核爆弾
