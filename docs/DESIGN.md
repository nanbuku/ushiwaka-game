# うしわか 設計メモ

## コンセプト

- TPS 視点で、元ぬいぐるみの白い小型犬「うしわか」を操作する
- 舞台は普通の人間界（架空の町）。田舎・都会・公園・遊園地・家など
- 大筋は「なんくが喜ぶように健気に物を届ける」育成ゲーム
- ただし遊び方は自由。盗む・噛みつく・吠えて気絶させる等のグレーな行動もできる
- 白いもふもふが暴れまわる滑稽さを楽しむ。表現は成人向け（流血・死亡あり、個人利用）

## 決定事項

| 項目 | 内容 |
|---|---|
| 主人公 | うしわか（犬）。元ぬいぐるみ。自分が生きていることはなんくも街の人も知っている |
| 飼い主 | なんく（25歳女性）。仕事・人間関係がうまくいかず、うしわかにずっと話しかけていた |
| 育成 | なんくの **幸福度**（0〜100）を上げる |
| 悪の分岐 | うしわかの **悪行** が 100 を超えると、なんくが悪に染まり、メーターが **悪魔度** に切り替わる（一方通行）。なんくはうしわかには常に優しいが、悪行が増えるほど他人へのセリフが酷くなる |
| エンディング | 幸福度 100 →「しあわせエンド」、悪魔度 100 →「あくまエンド」 |
| 昼夜 | 見た目のみ変化（ゲーム内容は同じ） |
| 対象 | PC（キーボード＋マウス）、ローカルで遊ぶ |
| 飛行機 | なし |
| グラフィック | 方針B（無料素材 Kenney を使う）。素材サイトが使えるまではコードで作った見た目で進める |
| GTA・どうぶつの森 | 雰囲気の参考のみ。UI・名前・地図・音楽は独自 |

## 悪行ポイント

| 行動 | 悪行 |
|---|---|
| 吠えて気絶させる | +1 / 人 |
| 盗む（お店・人の落とし物） | +2 |
| お供え物を盗む | +4 |
| 噛みつく | +3 |
| 噛み殺す・はねる・爆発に巻き込む | +12 / 人（子ども・お年寄りを噛み殺すと +16） |
| 爆弾を爆発させる | +5 |
| 車を盗む | +2 |

悪魔モード中は、悪行の半分が悪魔度に加算される。物を渡すと各アイテムの `devil` 値（盗品は +3）が加算される。

## コード構成

```
src/
  core/      Game（メインループ）, Physics（Rapier）, Input, Audio（効果音を合成）, Events, Rng
  world/     Layout（地区・道路・区画）, World, districts（各地区の建物）, Builder, Batcher, Kit（素材/マテリアル）, Sky（昼夜）, Navigation（歩行者経路）
  player/    Ushiwaka（操作）, DogModel（見た目・アニメ）, Fur（もふもふシェーダー）, CameraRig
  npc/       Human（人のモデル）, NPC（AI）, NPCManager（出現・消去）
  gameplay/  Items（拾える物）, Karma（幸福度・悪行・悪魔度・セーブ）, Nanku（なんく）, NankuLines（セリフ）
  fx/        Effects（血・衝撃波・星・水しぶき）
  ui/        HUD, Dialogue
```

## フェーズと進捗

### フェーズ1: 基本（済）
- [x] うしわかの操作（移動・ジャンプ・ダッシュ・泳ぐ）、TPS カメラ
- [x] 9地区の街（道路・歩道・建物・公園・遊園地・田舎）、昼夜サイクル
- [x] 噛みつく（流血・死亡）、吠える（気絶）、大吠え、くわえる・投げる
- [x] 通行人 AI（歩く・逃げる・反撃・気絶・死亡・持ち物を落とす）、店員
- [x] 盗み判定（お店・お供え物・人の持ち物）と商品の補充
- [x] なんく: 会話・贈り物・幸福度、悪行による闇落ちイベント、悪魔モード、エンディング
- [x] HUD（ゲージ・ミニマップ・地図・通知）、効果音、セーブ

### フェーズ2: 生活と追っ手
- [x] 通報レベルと保健所（目撃者が通報 → 保健所の職員が網で追ってくる → 捕まると檻へ → なんくがお迎え）
- [x] なんくのおつかい（依頼）システム、悪魔モード用の依頼（全15種）
- [x] なんくの家の中（リビング・寝室・テレビのニュースがうしわかの悪事を報道）
- [ ] Kenney 素材への差し替え（建物・家具・車・人）※ kenney.nl がネットワーク設定で未許可

### フェーズ3: 乗り物
- [x] 車・タクシー・バン・軽トラ・スクーター・保健所の車を運転（F で乗り降り、運転手を追い出してカージャック）
- [x] 交通（左側通行の車線を AI の車が走る。前の車や人で減速、よそ見運転の車はうしわかに気づかない）
- [x] 人をはねる（速いと吹っ飛んで死亡、遅いと気絶）、うしわかがはねられる
- [x] エンジン音・クラクション・衝突音、速度計

### フェーズ4: 仕上げ
- [x] 爆弾（繁華街の花火屋「ドカン堂」、河川敷の危険物倉庫で入手）。Q で投げると導火線に火がつき、爆発で人も車も吹っ飛ぶ
- [x] BGM（その場で作曲。悪魔モードでは短調に変わる。N で ON/OFF）
- [ ] 遊園地の乗り物、ジェットコースター
- [ ] 演出・バランス調整
