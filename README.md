# うしわか

元ぬいぐるみの白いもふもふ犬「うしわか」を操作して、人間界を自由に駆けまわる 3D オープンワールド育成ゲームです（ブラウザで動きます）。

飼い主の **なんく**（25歳）は、仕事も人間関係もうまくいかない毎日。
「うしわかが本当の友達だったらいいのに」という願いがかなって、ぬいぐるみのうしわかに命が吹き込まれました。

- 街で見つけた物をくわえて届けると、なんくの **幸福度** が上がります（満タンで「しあわせエンド」）
- …でも、うしわかは何をしてもかまいません。噛みつく、盗む、吠えて気絶させる、車を乗っ取ってはねる、
  金属バット・チェーンソー・ロケット花火・火炎瓶・撒菱・リモコン爆弾・拡声器で暴れる。
  **悪行** が 100 を超えると、なんくも悪に目覚め、目標が **悪魔度** に変わります（満タンで「あくまエンド」）

## 遊び方（ローカル）

[Node.js](https://nodejs.org/) 20.19 以上（または 22.12 以上）が必要です。

```bash
npm install
```

```bash
npm run dev
```

表示された URL（通常は http://localhost:5173 ）をブラウザ（Chrome 推奨）で開いてください。

## 操作

| 操作 | キー |
|---|---|
| 移動 / 走る / ジャンプ | WASD / Shift / Space |
| カメラ / ズーム | マウス / ホイール |
| 噛みつく（物をくわえる） | 左クリック |
| 吠える / 大吠え | 右クリック / 右クリック長押し |
| くわえる・はなす・なんくと話す | E |
| くわえた物を投げる | Q |
| 乗り物に乗る・降りる | F（運転は WASD、Space でサイドブレーキ／ドリフト、右クリックでクラクション。走行中に F で飛び降り） |
| 武器の持ち替え | 1〜8 / R（武器は街のあちこちに落ちている。地図のオレンジの点） |
| 仕掛けたリモコン爆弾をまとめて起爆 | G |
| 地図 | M（押している間。黄色い印がおつかいの目的地） |
| 音楽 ON/OFF | N |
| 一時停止 | Esc |

## 街の構成（600m × 600m、9地区）

| | 西 | 中央 | 東 |
|---|---|---|---|
| 北 | 山あいの集落 | みどり公園 | わくわくランド（遊園地） |
| 中 | 田園地帯 | ひだまり町（なんくの家・商店街・スーパー） | オフィス街 |
| 南 | 河川敷・工場 | 学校・病院・保健所 | 繁華街 |

## 開発

```bash
npm run typecheck
```

```bash
npm run build
```

- 技術: TypeScript + [Three.js](https://threejs.org/) + [Rapier](https://rapier.rs/)（物理）+ Vite
- 設計と進捗: [docs/DESIGN.md](docs/DESIGN.md)
- テスト用: URL に `?test` を付けるとタイトルを飛ばして即開始します（`window.__game` からゲームの状態を操作できます）

## 素材

3D モデルは [Kenney](https://kenney.nl/)（CC0）の City Kit (Commercial / Suburban / Roads)、Car Kit、Nature Kit、Furniture Kit、Food Kit、Animated Characters を使っています。
元の ZIP は `assets-src/kenney/`、ゲームで読み込むファイルは `public/models/` にあります。
URL に `?noassets` を付けると、素材を使わずにコードで作った見た目で起動します（動作が重いとき用）。
