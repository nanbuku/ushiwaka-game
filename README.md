# うしわか

元ぬいぐるみの白いもふもふ犬「うしわか」を操作して、人間界を自由に駆けまわる 3D オープンワールド育成ゲームです（ブラウザで動きます）。

飼い主の **なんく**（25歳）は、仕事も人間関係もうまくいかない毎日。
「うしわかが本当の友達だったらいいのに」という願いがかなって、ぬいぐるみのうしわかに命が吹き込まれました。

- 街で見つけた物をくわえて届けると、なんくの **幸福度** が上がります（満タンで「しあわせエンド」）
- …でも、うしわかは何をしてもかまいません。噛みつく、盗む、吠えて気絶させる、車や戦車を乗っ取ってはねる、
  金属バット・チェーンソー・拳銃・マシンガン・ロケット花火・追尾ミサイル・火炎瓶・リモコン爆弾・**核爆弾**・撒菱・拡声器で暴れる（武器は一度拾えば無制限）。
  家・ビル・木・街灯は壊せます。
- 暴れるほど通報レベルが上がり、**保健所 → 警察（警告してから発砲）→ パトカー → SWAT → 防衛隊（小銃・戦車）** と追っ手が強くなります
  **悪行** が 100 を超えると、なんくも悪に目覚め、目標が **悪魔度** に変わります（満タンで「あくまエンド」）

## メインストーリー

ゲームを始めてしばらくすると、メインストーリー（悪の会社〈株式会社グレイハート〉との戦い）が始まります。
画面右の欄に目的が出て、黄色い印と矢印が行き先を案内します。追っ手がいないときに次の章が始まります。

1. 灰色の帰り道 ― タワー前のドレインライトを壊す
2. 白い犬を捕まえろ ― 追っ手から逃げ、黒服からなんくの家を守る
3. くまきち、目覚める ― 相棒くまきちと、街のドレインライト破壊・仲間の救出
4. ネジマキ博士の工場 ― グレイエンジン破壊、ボス：ガラクタ戦車
5. グレイハートタワー ― ボス：鉄面 剛、ブラックドーベル
6. 終章 ― 巨大怪獣〈グレイ〉との決戦（幸福度ルート／悪魔度ルートでエンディングが変わる）

## 遊び方（ローカル）

[Node.js](https://nodejs.org/) 20.19 以上（または 22.12 以上）が必要です。

```bash
npm install
```

```bash
npm run dev
```

表示された URL（通常は http://localhost:5173 ）をブラウザ（Chrome 推奨）で開いてください。

## 操作

| 操作 | キー |
|---|---|
| 移動 / 走る / ジャンプ | WASD / Shift / Space（空中でもう一度 Space で二段ジャンプ、壁に向かって Space で壁ジャンプ、落下中に長押しで耳で滑空） |
| ダッシュ | C または Ctrl |
| 回転アタック / もふもふシールド / 死んだふり | V / X / Z（死んだふり中は追っ手に見失われる） |
| カメラ / ズーム | マウス / ホイール |
| 噛みつく（物をくわえる） | 左クリック |
| 吠える / 大吠え | 右クリック / 右クリック長押し |
| くわえる・はなす・なんくと話す | E |
| くわえた物を投げる | Q |
| 乗り物に乗る・降りる | F（運転は WASD、Space でサイドブレーキ／ドリフト、右クリックでクラクション。走行中に F で飛び降り） |
| 武器の持ち替え | 1〜9, 0, -, ^ / R（武器は街のあちこちに落ちている。地図のオレンジの点） |
| 銃・ミサイル | 画面中央の照準に向けて撃つ（マシンガンは長押しで連射、ミサイルは照準の近くの人・車を追いかける） |
| 核爆弾 | 足元に置くと10秒後に半径約160mが消し飛ぶ（全力で逃げる） |
| 戦車 | W/S 前進・後退、A/D その場で旋回、マウスで砲塔、左クリックで主砲（河川敷の工場の奥にある） |
| 仕掛けたリモコン爆弾をまとめて起爆 | G |
| 地図 | M（押している間。黄色い印がおつかいの目的地） |
| 音楽 ON/OFF | N |
| 一時停止 | Esc |

## 開発

```bash
npm run typecheck
```

```bash
npm run build
```

- 技術: TypeScript + [Three.js](https://threejs.org/) + [Rapier](https://rapier.rs/)（物理）+ Vite
- 設計と進捗: [docs/DESIGN.md](docs/DESIGN.md)
- テスト用: URL に `?test` を付けるとタイトルを飛ばして即開始します（`window.__game` からゲームの状態を操作できます）

## 素材

3D モデルは [Kenney](https://kenney.nl/)（CC0）の City Kit (Commercial / Suburban / Roads)、Car Kit、Nature Kit、Furniture Kit、Food Kit、Animated Characters を使っています。
元の ZIP は `assets-src/kenney/`、ゲームで読み込むファイルは `public/models/` にあります。
URL に `?noassets` を付けると、素材を使わずにコードで作った見た目で起動します（動作が重いとき用）。
